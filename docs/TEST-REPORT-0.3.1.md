# MineOrbit 0.3.1 验证报告 · 2026-11-10

Windows x64，.NET 10，WPF。此次修复小窗口操作和设置保存。之前功能的验证见 TEST-REPORT-0.3.md 与 TEST-REPORT-0.2.md。

## 修复内容

- 最小窗口 760 × 480；较窄窗口自动收紧侧栏，七个导航入口均可显示。侧栏自身也能滚动，避免内容超过高度时被直接裁掉。
- 页面保留隐藏滚动条，固定底部增加上下翻页按钮。列表滚动到边缘时把滚轮交给外层页面。
- 设置页保存按钮固定在底部。按钮与开关长文字可换行；设备码提示高度受到限制且可滚动，保留页面操作空间。
- 设置文本绑定改为输入时更新，包括数字转换错误提示。正常关闭窗口会等待设置保存完成再退出；无效输入或保存异常会提示并保留窗口。强制结束进程不属于正常关闭，不保证保存尚未提交的更改。
- 保存上次页面、所选游戏版本和窗口大小。更改其他设置不再无条件重建认证服务。CurseForge Key 仍通过 DPAPI 加密保存，不在输入框回显。

## 验证结果

- Release 编译通过。58 项测试全部通过：artifacts/test-results/phase3.1.trx。
- 新增设置完整往返测试，使用新的 SettingsService 重新读取：数据目录、Java 路径、Client ID、登录方式、内存、游戏尺寸、隔离默认值、并发、缓存开关和目录、页面、所选版本与窗口尺寸均保留。Key 加密保存且不进入明文 JSON；无效保存不会覆盖上次有效配置。
- 新增实际 WPF 控件测试：在独立 STA / Dispatcher 中加载 App 资源、MainWindow 和真实 ViewModel，使用临时目录及临时配置。
- 在约 704 × 400 客户区的布局下逐页测量，七个导航项均在范围内，七页内容可滚至末尾，页面按钮横向无裁切，固定保存按钮在范围内。
- 实际 WPF TextBox、ComboBox、CheckBox 输入后无需移出焦点即可保存。非法数字产生验证状态。列表边缘发送滚轮事件后，外层页面实际移动。长设备码提示不会压掉页面空间。
- 在不激活、不显示任务栏的屏幕外测试窗口执行真正的 Close 事件，确认输入框最后一笔内容和 760 × 480 窗口尺寸被写入，再用新的 SettingsService 读取确认。
- 渲染设置页图像并检查布局：artifacts/test-results/small-window-settings.png。测试不修改用户的实际配置、账号或游戏目录。

本轮没有重新进行真人 Microsoft 授权或 Minecraft 游戏启动。多显示器、高 DPI 与更多窗口尺寸仍需进一步验证。
